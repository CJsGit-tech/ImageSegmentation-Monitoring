# ImageSegmentation-Monitoring

Image analysis and real-time AI performance monitoring tasks.

- [Image segmentation](image-segmentation/README.md): animal and eye segmentation,
  sample images, model notes, and Python dependencies.
- [Project requirements](QUESTIONS.md): requirements for both project tasks.

The existing Python environment remains at `.venv/` in this repository root.

Run the segmentation from here:

```bash
.venv/bin/python image-segmentation/segment_animals_eyes.py
open image-segmentation/output
```
