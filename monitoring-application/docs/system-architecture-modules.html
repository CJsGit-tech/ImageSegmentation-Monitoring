元件與責任

元件技術模組責任
前端容器Streamlit①②③④⑤每個模組一組頁面；保存登入 Token 與即時資料緩衝；以客戶端呼叫後端 REST，並接收 WebSocket 即時資料。
REST API／WebSocket 端點FastAPI、Pydantic①②③④⑤REST 提供各模組功能並附 Swagger 文件；WebSocket 推送即時資料。
JWT 認證與角色權限JWT①（供全部使用）驗證登入 Token，依 Admin、User、Viewer 角色限制操作。
① 使用者管理後端模組①註冊、登入、角色與權限控制。
② 資料管理後端模組②資料記錄 CRUD、分頁篩選排序、擁有者檢查、CSV／JSON 批量導入。
③ 即時監控後端模組、背景任務③模擬器產生資料，判定異常，經 WebSocket 推送並批次寫入。
④ 資料分析後端模組④統計、時間範圍查詢、分類聚合、趨勢與 Excel 匯出。
⑤ 系統管理後端模組⑤使用者列表與權限、系統日誌、資料庫狀態、即時資料歷史查詢。
資料存取層SQLAlchemy、asyncmy、Alembic全部所有資料庫操作經 ORM 與連接池；Alembic 管理結構遷移。
資料庫容器MariaDB 11.7全部保存使用者、資料記錄、導入紀錄、異常範圍與系統日誌；以 Docker Volume 持久化。
