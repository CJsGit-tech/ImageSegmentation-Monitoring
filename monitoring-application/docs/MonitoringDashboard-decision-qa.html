PRD-06 規則 R5
M2·Q4

同一個檔案被上傳兩次時，怎麼處理？

已決定

只檢查檔案名稱。相同檔名已成功導入過時，拒絕上傳並要求改名後再上傳。

不比對檔案內容，內容相同的列照單全收。因有問題而整批被拒絕的檔案不算已導入，可用原檔名重新上傳。

PRD-06 規則 R7
M2·Q5

刪除資料記錄後還能復原嗎？

已決定

不能。刪除是永久刪除，刪除前須確認，確認後記錄無法復原，也不再出現在列表與分析中。

例外：被標為異常的記錄不能被刪除（見 M4 Q4）。

PRD-05 規則 R5、R7
M2·Q6

誰可以修改與刪除資料？

已決定

僅限該記錄的創建者或 Admin。User 只能處理自己建立的記錄，Admin 可處理任何人的記錄，Viewer 不能修改或刪除。

後端會驗證，直接呼叫 API 時沒有權限的操作同樣被拒絕。

例外：被標為異常的記錄，任何人（含 Admin）都不能修改或刪除（見 M4 Q4）。

PRD-05 規則 R1、R2、R3
M2·Q7

已決定

可更改標題、數值、分類、時間戳。

記錄上的「創建者」欄位固定為原本建立它的人，不能被改成別人。這不影響權限：創建者仍可修改與刪除自己的記錄。

不保留修改紀錄，記錄只保存最新內容。

M3·Q1

異常的閾值怎麼訂？每個設備都有各自的閾值時，怎麼辨識設備？

已決定

資料視為時間序列：一筆記錄是某個分類（代表一個指標或設備）在某個時間點的一次讀數，以「分類」區分設備，不新增欄位。

每個分類各有自己的最小值與最大值，由 Admin 在系統管理設定與修改，修改後不需要重新啟動。其他角色不能修改。

修改範圍只影響之後的資料，已保存的資料不回頭重判。

M3·Q7

PRD-08 規則 R7 到 R11
M3·Q8

即時監控頁的互動範圍到哪裡？

已決定

有兩種檢視：「即時窗口」持續自動更新；「自訂時間範圍」可指定開始與結束時間，單次最長 3 個月，超過時拒絕並說明上限。

6 / 8 已決定
M4·Q1

三個「按時間範圍看歷史」的地方怎麼分工？單次可以查多久？

已決定

三處各司其職：即時監控頁的自訂時間範圍檢視（PRD-08）用來看當時的監控畫面與異常；資料分析頁（PRD-10 到 PRD-12）提供統計、分類聚合、趨勢圖與 Excel；Admin 的即時資料歷史查詢（M5）列出原始記錄供追查。

三處共用同一個上限：單次查詢最長 3 個月，超過時拒絕並說明上限。要看更長的期間就分批查，一次查一段。

已決定

只顯示需求中的四項：總計、平均、最大值、最小值，不另加筆數或異常筆數。依分類聚合時，每個分類各自顯示這四項。

PRD-10 規則 R1、R3、R10
M4·Q3

異常的記錄要怎麼特別保留供查看？

已決定

資料分析頁有獨立的「異常記錄」清單，可依時間範圍（同樣受 3 個月上限）與分類查看，並支援分頁。所有已登入角色都能查看（依 PRD-09 的提案）。

資料列表另有「僅顯示異常」的篩選，沒有時間上限（兩者並存）。

PRD-10 規則 R11（故事 US-22）PRD-09 規則 R11
M4·Q4

異常記錄能被修改或刪除嗎？

已決定

不能。被標為異常的記錄完全唯讀，任何人（含 Admin）都不能修改或刪除，以確保事後可追查。此規則優先於一般的修改與刪除權限，由 PRD-18（故事 US-23）擁有，PRD-05 只保留指向它的說明。

一般記錄被修改成超出範圍後成為異常，之後即唯讀。副作用：異常記錄一旦產生就無法更正，即使當初填錯。

PRD-18 規則 R1 到 R5PRD-09 規則 R12
M4·Q5

下載的 Excel 要包含什麼？

已決定

兩個工作表。「摘要」列出查詢條件（時間範圍、分類），以及總計、平均、最大值、最小值，依分類聚合時每個分類各一列。

「明細」列出該條件下範圍內的記錄（標題、數值、分類、時間戳、創建者），被標為異常的列有明確標示。不放趨勢圖。

所有已登入角色（含 Viewer）都能下載；條件內沒有資料時不產生檔案；檔名含產生的日期時間（提案）。

PRD-13 規則 R2、R7
M5·Q4

系統日誌要記錄哪些事件？

已決定

登入成功與失敗、登出、因重複登入而使舊登入失效、權限被拒、使用者角色變更、資料記錄的新增／修改／刪除、批量導入的結果、系統錯誤。

系統每秒產生的模擬資料不列入日誌。每筆日誌至少含時間、事件類型、嚴重程度、相關使用者與簡短說明（後者為提案）。

PRD-14 規則 R6、R7
M5·Q5

日誌可以怎麼查？保留多久？

已決定

可依時間範圍、事件類型、嚴重程度、使用者過濾，條件可同時使用；不做關鍵字搜尋。

單次查詢最長 3 個月，與其他歷史查詢一致。日誌保留 1 年，超過的自動清理，保留期限可調整（設定方式屬工程選型）。結果分頁、最新的在前、唯讀。
